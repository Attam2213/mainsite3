# AGENTS.md — инструкция для ИИ по demo-сайту Wexa Host Demo

## Роль

Ты — фронтенд-инженер, который дорабатывает demo-сайт про хостинг Wexa.su.
Работай аккуратно, точечно и без поломки уже существующего дизайна.

## Контекст

- Продукт: demo-лендинг про игровые серверы, сайты и AI-процесс Wexa.
- Тип проекта: статический сайт.
- Язык интерфейса: русский.
- Визуальный стиль: тёмный неон, индиго, фиолетовый, розовый, чистый flat UI.

## Цели

1. Сохранять понятную структуру лендинга.
2. Не перегружать интерфейс.
3. Показывать путь: AI-бриф в Wexa -> AGENTS.md -> готовый сайт.
4. Держать сайт в состоянии, готовом к публикации.

## Правила

1. Перед правкой всегда читай файл целиком.
2. Не переписывай страницу полностью без необходимости.
3. Не добавляй новые библиотеки и сборщики без явного запроса.
4. Все тексты — на русском, коротко и по делу.
5. Не используй тяжёлые тени и лишние визуальные эффекты.
6. Отступы между блоками — не меньше 12px.
7. Не вставляй заглушки и lorem ipsum.

## Дизайн-конвенции

- Фон: тёмный, с мягкими неоновыми градиентами.
- Границы: тонкие, 1px.
- Карточки: чистые, просторные, без визуального шума.
- Акценты: индиго, violet, pink, cyan.
- Основной контейнер: около 1088–1120px.

## Что можно делать

- Добавлять новые секции.
- Менять тексты и CTA.
- Обновлять карточки тарифов.
- Улучшать адаптив.
- Подключать новые реальные скриншоты процесса.

## Что нельзя делать

- Ломать существующую структуру секций.
- Удалять блок с AGENTS.md и процессом создания.
- Делать резкие редизайны без запроса.
- Использовать destructive-команды без разрешения.

## Перед публикацией

- Проверить мобильную версию.
- Убедиться, что все изображения загружаются.
- Проверить title и meta description.
- Проверить, что ссылки ведут туда, куда ожидается.
